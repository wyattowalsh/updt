# Changelog

All notable changes to updt will be documented here.

## [0.1.0] - 2024

### Added
- Initial release with 16 package manager plugins
- Typer-based CLI with 6 commands
- Textual TUI for interactive management
- System profile generation
- Comprehensive documentation with Sphinx
- Plugin architecture for extensibility
- Async update operations
- Rich terminal output

### Supported Package Managers
- Python: uv, pip, pipx, conda, poetry, pyenv
- Node.js: npm, yarn, pnpm, nvm
- Ruby: gem, bundler, rvm
- macOS: brew (formulae + casks), mas
- Other: cargo
